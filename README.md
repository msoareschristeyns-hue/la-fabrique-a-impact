# La Fabrique à Impact

**La RSE qui fait avancer votre PME.**

La Fabrique à Impact est un copilote RSE conçu pour transformer la complexité RSE en priorités, actions et preuves concrètes pour les PME.

## Boucle produit

Diagnostiquer → Prioriser → Agir → Prouver → Valoriser → Progresser

## MVP V2

- Homepage orientée proposition de valeur et conversion
- Diagnostic express
- Dashboard signature « Mes 3 priorités »
- Indicateurs de progression, actions, preuves et exigences clients
- Première expérience du copilote RSE
- Design responsive

## Stack

Next.js 14 · React · TypeScript · Supabase (préparé pour l'étape authentification/données)

## Démarrage

```bash
npm install
npm run dev
```
